Kapitel 06 · Fråga 1

När passar en for-loop respektive en while-loop bäst?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 06 · Facit 1

for passar när man vet vad eller hur många gånger man ska gå igenom. while upprepar så länge ett villkor är sant.

for i in range(5):
    print(i)

while count <= 5:
    count += 1

Kapitel 06 · Fråga 2

Vilka tal skapar range(5), och varför ingår inte 5?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 06 · Facit 2

range(5) skapar 0, 1, 2, 3 och 4. Stoppvärdet ingår inte.

for i in range(5):
    print(i)

Loopen körs fem gånger.

Kapitel 06 · Fråga 3

Hur fungerar range(start, stopp, steg)?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 06 · Facit 3

start är första talet, stopp är gränsen som inte tas med och steg anger hur mycket talet ändras.

for i in range(2, 11, 2):
    print(i)

Exemplet skriver ut 2, 4, 6, 8 och 10.

Kapitel 06 · Fråga 4

Hur uppstår en oändlig while-loop, och hur kan den undvikas?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 06 · Facit 4

Den uppstår när villkoret aldrig blir False. Ändra variabeln som styr villkoret i loopen.

count = 1
while count <= 5:
    print(count)
    count += 1

Utan ökningen skulle count alltid vara 1.

Kapitel 06 · Fråga 5

Vad gör break i en loop?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 06 · Facit 5

break avslutar loopen direkt, även om loopens villkor fortfarande är sant.

while True:
    number = int(input("Tal: "))
    if number == 0:
        break

Här fungerar 0 som stoppvärde.
