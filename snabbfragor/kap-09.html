Kapitel 09 · Fråga 1

Vad är ett syntaxfel?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 09 · Facit 1

Ett syntaxfel betyder att koden inte följer Pythons skrivregler, så programmet kan inte köras.

if age >= 18:
    print("Myndig")

Vanliga syntaxfel är saknade parenteser, kolon, indrag eller felstavade kommandon.

Vad är ett logiskt fel?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 09 · Facit 2

Programmet kan köras men ger fel resultat eftersom lösningen eller beräkningen är fel.

average = (a + b) / 2

Logiska fel ger ofta inget felmeddelande och hittas genom testning.

Kapitel 09 · Fråga 3

Vad är ett exekveringsfel?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 09 · Facit 3

Det är ett fel som uppstår medan ett syntaktiskt korrekt program körs och får programmet att krascha.

number = int(input("Tal: "))
print(10 / number)

Text i stället för tal eller talet 0 kan orsaka fel här.
