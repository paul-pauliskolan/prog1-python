Kapitel 08 · Fråga 1

Vad är en funktion, och varför används funktioner?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 08 · Facit 1

En funktion är en namngiven del av programmet som utför en bestämd uppgift. Funktioner gör kod lättare att läsa, ändra och återanvända.

def greet():
    print("Hej!")

greet()

def skapar funktionen och greet() anropar den.

Kapitel 08 · Fråga 2

Vad är en parameter, och vad är ett argument?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 08 · Facit 2

En parameter är ett namn i funktionsdefinitionen. Ett argument är värdet som skickas in när funktionen anropas.

def greet(name):
    print(f"Hej {name}")

greet("Ada")

name är parametern och "Ada" är argumentet.

Kapitel 08 · Fråga 3

Vad gör return i en funktion?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 08 · Facit 3

return skickar tillbaka ett värde till platsen där funktionen anropades.

def add(a, b):
    return a + b

result = add(4, 6)

Det returnerade värdet kan sparas eller användas i en ny beräkning.

Kapitel 08 · Fråga 4

Hur får man ett slumpat heltal från 1 till och med 6?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 08 · Facit 4

Importera modulen random och anropa random.randint(1, 6). Båda gränserna kan väljas.

import random
number = random.randint(1, 6)

Resultatet kan vara vilket heltal som helst från 1 till 6.

Kapitel 08 · Fråga 5

Hur kan funktioner ge ett större program en tydligare struktur?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 08 · Facit 5

Dela upp programmet så att varje funktion har en tydlig uppgift, placera funktionerna överst och huvudprogrammet längst ner.

def square(number):
    return number * number

value = int(input("Tal: "))
print(square(value))

Små funktioner blir lättare att testa och återanvända.
