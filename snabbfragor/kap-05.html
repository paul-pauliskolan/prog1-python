Kapitel 05 · Fråga 1

Vad gör en if-sats, och när körs den indragna koden?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 05 · Facit 1

En if-sats kontrollerar ett villkor. Den indragna koden körs bara när villkoret är True.

age = 18
if age >= 18:
    print("Du är myndig")

Kolonet och indraget visar vilken kod som hör till villkoret.

Kapitel 05 · Fråga 2

Vad är skillnaden mellan if, elif och else?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 05 · Facit 2

if testar första villkoret, elif testar fler villkor och else körs om inget villkor var sant.

if temperature < 10:
    print("Kallt")
elif temperature <= 20:
    print("Lagom")
else:
    print("Varmt")

Villkoren kontrolleras uppifrån och ner.

Kapitel 05 · Fråga 3

Hur kan operatorn % användas för att avgöra om ett tal är jämnt?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 05 · Facit 3

Ett tal är jämnt om resten vid division med 2 är 0.

if number % 2 == 0:
    print("Jämnt")
else:
    print("Udda")

% ger resten efter en division.

Kapitel 05 · Fråga 5

Vad är ett nästlat villkor?

Tänk på svaret först. Tryck sedan på mellanslag för att visa facit.

Kapitel 05 · Facit 5

Det är en if-sats inuti en annan if-sats. Det inre villkoret kontrolleras bara om det yttre leder dit.

if age >= 18:
    if has_license == "ja":
        print("Du får köra")

Varje nivå får ytterligare ett indrag.
