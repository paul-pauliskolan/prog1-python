6.1

En loop upprepar kod

Utan loop måste samma instruktion skrivas flera gånger.

print(1)
print(2)
print(3)
print(4)
print(5)

Samma resultat

Kortare kod med en loop

for i in range(5):
    print(i + 1)

Den indragna instruktionen är print(i + 1).

Den körs fem gånger med olika värden på i.

6.4

range(stopp)

for i in range(5):
    print(i)

range(5) börjar på 0.

Stoppvärdet 5 ingår inte.

Följden blir 0, 1, 2, 3, 4.

range()

Start och stopp

for i in range(1, 6):
    print(i)

Startvärdet 1 ingår.

Stoppvärdet 6 ingår inte.

Följden blir 1, 2, 3, 4, 5.

6.5

En oändlig loop tar aldrig slut

while True:
    print("Detta fortsätter för alltid")

Villkoret är alltid sant.

En sådan loop behöver ett annat sätt att avslutas, exempelvis break.

Oändlig av misstag

Variabeln ändras inte

count = 0

while count < 5:
    print(count)

count förblir 0.

Villkoret 0 < 5 fortsätter därför att vara sant.

Rätta loopen

För villkoret mot False

count = 0

while count < 5:
    print(count)
    count = count + 1

Efter fem varv blir count lika med 5.

Då blir villkoret falskt och loopen avslutas.

6.6

Villkoret kan ändra varje varv

for i in range(1, 11):
    if i % 2 == 0:
        print(f"{i} är jämnt")
    else:
        print(f"{i} är udda")

Loopen väljer en gren för varje tal.

Loop och input

Användaren bestämmer antalet varv

number = int(input("Hur många tal? "))

for i in range(1, number + 1):
    if i % 2 == 0:
        print(f"{i} är jämnt")
    else:
        print(f"{i} är udda")

number + 1 behövs eftersom stoppvärdet inte ingår.

Räknaren ökar bara när villkoret är sant.

6.8

break avslutar loopen direkt

while True:
    number = int(input("Skriv ett tal (0 avslutar): "))
    if number == 0:
        break
    print(f"Du skrev talet {number}")

När användaren skriver 0 lämnar programmet loopen.

break · körning

Stoppvärdet skrivs inte ut

Skriv ett tal (0 avslutar): 5

Skriv ett tal (0 avslutar): 8
Du skrev talet 8
Skriv ett tal (0 avslutar): 0

break körs innan den sista print()-raden.

Sammanfattning

Kom ihåg

  • while upprepar så länge ett villkor är sant.
  • for går igenom en talföljd eller samling.
  • Stoppvärdet i range() ingår inte.
  • En while-loop måste kunna nå ett falskt villkor.
  • Loopar kan innehålla villkor och bygga summor eller räknare.
  • break avslutar den aktuella loopen direkt.
