2.1

En variabel lagrar ett värde

Tänk på variabeln som en låda med en etikett.

Etikett: name→Värde: "Anna"
name = "Anna"

Varför variabler?

Använd information senare

  • Lagra information.
  • Använd samma värde flera gånger.
  • Ge värdet ett begripligt namn.
  • Byt värde när programmet körs.

2.2 · Tilldelning

= betyder ”tilldela”

name = "Anna"
age = 17

Python sparar värdet till höger under namnet till vänster.

= betyder inte matematiskt ”lika med” här.

Hela programmet

Skapa och använd variabler

name = "Pelle"
age = 18

print(name)
print(age)
Pelle
18

Steg för steg

Vad händer i minnet?

name = "Pelle"

Skapar namnet name och lagrar texten "Pelle".

age = 18

Skapar namnet age och lagrar heltalet 18.

print(name)

Hämtar värdet i name och skriver ut det.

2.4

Skriv ut ett variabelvärde

name = "Anna"

Variabeln får ett värde.

print(name)

Utan citattecken hämtas värdet i variabeln.

Anna

Detta blir programmets utskrift.

Text och värden

print() kan ta flera delar

name = "Anna"
age = 17
print("Hej", name)
print(name, age)
Hej Anna
Anna 17

Kommat gör att Python lägger in mellanslag mellan delarna.

F-strängar

Placera variabler i text

name = "Anna"
age = 17
print(f"{name} är {age} år gammal")
  • f står före det första citattecknet.
  • Variabelnamnen står mellan { och }.
  • Python ersätter namnen med deras värden.

F-sträng · resultat

Koden blir lätt att läsa

Kod

name = "Anna"
age = 17
print(f"Hej {name}")
print(f"{name} är {age} år")

Utskrift

Hej Anna
Anna är 17 år

2.5

input() väntar på ett svar

name = input("Vad heter du? ")

Frågan visas och programmet pausar.

Användaren skriver ett svar och trycker Enter.

Svaret sparas i variabeln name.

Hela programmet

Fråga och svara

name = input("Vad heter du? ")
city = input("Vilken stad bor du i? ")

print(f"Hej {name}")
print(f"Du bor i {city}")
Vad heter du? Erik
Vilken stad bor du i? Malmö
Hej Erik
Du bor i Malmö

Viktig regel

input() ger alltid text

age = input("Hur gammal är du? ")
print(type(age))

Om användaren skriver 17 blir datatypen ändå str.

Tangentbordet lämnar alltså text till programmet.

2.6 · Problem

Text och tal kan inte adderas

age = input("Hur gammal är du? ")
print(age + 5)

age är str, men 5 är int.

Python stoppar programmet med ett TypeError.

Typomvandling

Gör texten till ett heltal

age = int(input("Hur gammal är du? "))
print(age + 5)
  1. input() läser in text.
  2. int() omvandlar texten till ett heltal.
  3. Heltalet sparas i age.
  4. Nu kan Python beräkna age + 5.

Välj rätt omvandling

Tre användbara funktioner

FunktionResultatExempel
int()heltalint("17")
float()decimaltalfloat("21.5")
str()textstr(17)

Decimaltal

Använd float()

temperature = float(input("Vad är temperaturen? "))
print(temperature + 1)

Om användaren skriver 21.5 blir resultatet 22.5.

Ett decimaltal skrivs med punkt i Python.

Kontrollfråga

Vad skriver programmet ut?

age = int(input("Ålder: "))
print(f"Om fem år är du {age + 5} år")

Användaren skriver 17.

Svar: Om fem år är du 22 år.

Sammanfattning

Kom ihåg

  • En variabel har ett namn och lagrar ett värde.
  • = tilldelar ett värde.
  • Vanliga typer är int, float, str och bool.

  • input() ger alltid str.
  • Använd int() eller float() före beräkningar.
