Kapitel 1

Vad är programmering?

Från tydliga instruktioner till ditt första Pythonprogram.

Mål

Efter kapitlet ska du kunna...

  • förklara vad program och programmering är
  • beskriva hur Python kör kod
  • skriva, spara och köra ett enkelt program
  • förstå syntax, indrag och vanliga fel
  • använda specialtecken i text

1.1

Ett program är instruktioner

Datorn följer instruktionerna steg för steg.

Den gör exakt det som står i koden.

Program finns i appar, spel, banker, bilar och medicinsk utrustning.

1.2

Programmering är en process

  1. Analysera problemet.
  2. Planera en lösning.
  3. Skriv kod.
  4. Testa programmet.
  5. Förbättra programmet.

1.3 · Hela exemplet

Datorn räknar enligt koden

tal1 = 5
tal2 = 3
summa = tal1 + tal2
print(summa)

Utskrift: 8

Möjligheter och gränser

Snabb – men inte tankeläsare

Datorn kan

  • räkna snabbt
  • hantera mycket data
  • automatisera uppgifter

Datorn kan inte

  • förstå vad du menade
  • rätta otydliga instruktioner själv

1.4

Programspråk

Kod skrivs med regler och ord från ett programspråk.

Exempel: Python, Java, C#, JavaScript och C++.

Vi använder Python eftersom språket är tydligt och lättläst.

1.5 · Körflöde

Från kod till resultat

Kodfil→Python-tolk⇄Operativsystem⇄Hårdvara
  • Python-tolken läser koden och utför instruktionerna.
  • Tolken ber operativsystemet om tillgång till exempelvis skärm, tangentbord och filer.
  • Operativsystemet styr hårdvaran och skickar data tillbaka till tolken.
  • Tolken fortsätter programmet och visar resultatet för användaren.

Input och output

Programmet möter användaren

namn = input("Vad heter du? ")

input() läser in ett svar och sparar det i namn.

print(f"Hej {namn}")

print() visar en hälsning med det sparade namnet.

1.7

Installera Python 3

  1. Gå till python.org och välj Downloads.
  2. Ladda ner Python 3 för macOS.
  3. Öppna filen och slutför installationen.
  4. Python-versionen kan vara nyare än i läromedlet.

Kontrollera installationen

Fråga terminalen

python3 --version

Kommandot visar vilken version som är installerad.

Python 3.x.x

En version som börjar med 3 betyder att du är redo.

1.8 · IDLE

Testa Python direkt

Starta IDLE via Spotlight. Fönstret Python Shell öppnas.

print("Hej")

Tryck Enter. Python kör raden direkt och skriver Hej.

Första programfilen

Skriv, spara, kör

print("Hej världen")
  1. Välj File → New File.
  2. Skriv koden.
  3. Spara som hej.py.
  4. Kör med F5 eller Run → Run Module.

Filstruktur

Håll ordning från början

Pythonfiler ska ha filändelsen .py.

  2. Installera Python-tillägget från Microsoft.
  3. Öppna din kapitelmapp.
  4. Välj Python: Select Interpreter.

Öppna filen och klicka på Run-knappen uppe till höger.

1.11

Syntax är kodens regler

print("Hej världen")

Korrekt: texten står inom citattecken.

print(Hej världen)

Fel: Python kan inte tolka texten.

Indrag

Mellanslag visar kodstruktur

if True:
    print("Detta skrivs ut")

Raden under if har fyra mellanslag.

I VS Code omvandlas Tab normalt till fyra mellanslag.

Felsökning

Läs felmeddelandet

prin("Hej")
  • Vilken rad innehåller felet?
  • Vilken typ av fel visas?
  • Är kommandot rättstavat?
  • Saknas citattecken, parentes eller indrag?

Kontrollfråga

Vad är fel?

print("Hej världen"

Tänk efter innan du går vidare.

Svar: den avslutande parentesen ) saknas.

1.14

Tänk som en programmerare

  • Dela upp stora problem i mindre delar.
  • Beskriv vad som händer först, sedan och sist.
  • Testa ofta och rätta ett fel i taget.
  • Använd tydliga namn och var noggrann.

Problemlösning

Dela upp uppgiften

Problem: räkna ut ett medelvärde.

  1. Läs in talen.
  2. Lägg ihop talen.
  3. Räkna hur många tal som finns.
  4. Dela summan med antalet.

1.15 · Övning

Skriv ditt första program

  1. Skapa en egen .py-fil.
  2. Skriv ut Hej världen.
  3. Skriv sedan ut tre rader med flera print().
  4. Ändra en rad så att ditt namn skrivs ut.
  5. Kör efter varje ändring.

Övning · felsök

Gör ett fel med flit

print("Hej världen"
  1. Kör programmet.
  2. Läs hela felmeddelandet.
  3. Hitta raden och felets typ.
  4. Rätta koden och kör igen.

Sammanfattning

Kom ihåg

  • Program är tydliga instruktioner till datorn.
  • Python tolkar och kör koden steg för steg.
  • Spara program som .py och kör dem i IDLE eller VS Code.
  • Syntax, citattecken, parenteser och indrag måste vara rätt.
  • Programmering är att analysera, planera, testa och förbättra.
