# Kontroll av testprov kapitel 1–13

Installera testberoendet med `npm install --prefix tests` och kör från projektroten med `npm test --prefix tests`. Node.js 20 eller senare. Testerna gör inga riktiga Google-anrop.

Kontrollerar 1 000 slumpningar, facit, exakt fem rätt på varje position, inmatningskrav, rättning, felgenomgång, MD, kopiering, localStorage, JSON och bakåtkompatibel Apps Script-routing.
