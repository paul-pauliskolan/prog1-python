# To-Do: Improve Multiple-Choice Questions

Use this checklist when revising multiple-choice questions. The goal is to make each question measure the intended knowledge or skill rather than the student's ability to spot clues, eliminate obviously wrong answers, or decode awkward wording.

## 1. Start from the learning objective

- [ ] Identify exactly what knowledge or skill the question is supposed to assess.
- [ ] Make sure multiple choice is an appropriate format for that objective.
- [ ] Rewrite or remove questions that mainly test trivial facts when the intended objective is deeper understanding.
- [ ] Prefer questions that require application, interpretation, comparison, or reasoning when the course content supports this.
- [ ] Make sure a correct answer actually indicates mastery of the intended content.

## 2. Improve the question stem

- [ ] Write the stem so that the task is clear before the student reads the answer options.
- [ ] Remove unnecessary background information.
- [ ] Remove unnecessary technical vocabulary unless that vocabulary is itself part of the learning objective.
- [ ] Avoid confusing sentence structures.
- [ ] Avoid double negatives and unnecessarily negative wording such as “Which statement would never be false?”
- [ ] If a negative is necessary, make it very clear what the student is being asked to identify.
- [ ] Put as much shared wording as possible in the stem instead of repeating it in every option.
- [ ] Do not include grammatical clues that reveal the correct answer.
- [ ] Do not include wording in the stem that directly points to one answer option.

## 3. Make every distractor plausible

- [ ] Treat the incorrect options as carefully as the correct answer.
- [ ] Replace obviously silly or absurd distractors.
- [ ] Do not use joke answers as distractors.
- [ ] Make every distractor believable to a student who has an incomplete or incorrect understanding.
- [ ] Base distractors on common misconceptions, common calculation errors, or typical reasoning mistakes.
- [ ] Make distractors diagnostically useful: a wrong answer should ideally reveal what the student misunderstood.
- [ ] Keep distractors within the same conceptual category as the correct answer.
- [ ] Avoid options that can be eliminated without knowing the course content.

## 4. Remove clues to the correct answer

- [ ] Make answer options similar in grammatical structure.
- [ ] Make answer options reasonably similar in length and level of detail.
- [ ] Do not make the correct answer noticeably longer, more precise, or more carefully explained than the distractors.
- [ ] Avoid giving extra definitions or qualifications only in the correct option.
- [ ] Avoid repeating distinctive words from the stem only in the correct answer.
- [ ] Check whether students can identify the correct answer simply by test-taking strategy.

## 5. Avoid “all of the above” and “none of the above”

- [ ] Remove “all of the above” whenever possible.
- [ ] Replace it with an option that requires the student to evaluate the full content directly.
- [ ] Remove “none of the above” when it allows the student to answer without knowing the actual correct information.
- [ ] Make sure the question requires positive knowledge of the intended answer, not only recognition that the other options are wrong.

## 6. Make each question independent

- [ ] Check whether one question gives away the answer to another.
- [ ] Remove repeated facts that become clues elsewhere in the test.
- [ ] Avoid using one earlier question to provide information required by a later question.
- [ ] Review the full test, not just each item in isolation.
- [ ] If questions are randomized, make sure they still work in any order.

## 7. Make the options fair

- [ ] Make all options grammatically compatible with the stem.
- [ ] Avoid article clues such as “a” versus “an” when only one option fits grammatically.
- [ ] Use parallel wording and sentence structure.
- [ ] Avoid one option being much more specific than the others.
- [ ] Avoid overlapping options unless the overlap is intentional and part of the reasoning being tested.
- [ ] Make sure there is one clearly best answer.

## 8. Test understanding, not cultural familiarity

- [ ] Remove humor, references, idioms, or cultural knowledge that are unrelated to the learning objective.
- [ ] Avoid distractors that are easy only because the student recognizes a joke or cultural reference.
- [ ] Make wording accessible to students whose first language may not be English.
- [ ] Keep language difficulty appropriate to the subject being assessed.

## 9. Avoid construct-irrelevant difficulty

- [ ] Do not make the question difficult simply through complicated wording.
- [ ] Do not turn a content question into a reading-comprehension or logic puzzle unless that is the objective.
- [ ] Make sure students who know the content are able to demonstrate that knowledge.
- [ ] Remove ambiguity that could cause a knowledgeable student to choose the wrong answer.
- [ ] Check whether low performance could be caused by poor item design rather than lack of knowledge.

## 10. Make the score meaningful

- [ ] Ask whether a high score would genuinely indicate strong knowledge of the assessed content.
- [ ] Ask whether a low score could incorrectly suggest weak knowledge because the questions are unclear.
- [ ] Remove unrelated bonus questions or extra-credit items that measure something outside the course objective.
- [ ] Make sure every scored item contributes to the interpretation of the final score.
- [ ] Do not reward unrelated background knowledge, hobbies, cultural knowledge, or guessing strategies.

## 11. Review the complete set of questions

- [ ] Create or use a test blueprint that maps questions to learning objectives.
- [ ] Check that important objectives receive appropriate coverage.
- [ ] Avoid over-representing minor facts simply because they are easy to turn into multiple-choice questions.
- [ ] Check whether the test includes a suitable balance of factual knowledge and higher-order thinking.
- [ ] Check whether the number of questions per objective reflects its importance.
- [ ] Remove redundant questions that test essentially the same thing.

## 12. Final quality check for every item

For each multiple-choice question, verify:

- [ ] What exact objective does this question assess?
- [ ] Does the student need subject knowledge to answer it correctly?
- [ ] Can the answer be guessed from grammar, length, wording, or formatting?
- [ ] Are all distractors plausible?
- [ ] Do the distractors represent meaningful misconceptions or mistakes?
- [ ] Is there exactly one clearly best answer?
- [ ] Is the wording simple and unambiguous?
- [ ] Does another question reveal the answer?
- [ ] Would a knowledgeable student understand exactly what is being asked?
- [ ] Would the answer provide useful evidence about what the student knows?

## Instruction to the AI

When revising my multiple-choice questions, do not merely improve grammar. Evaluate every question as an assessment item.

For each question:

1. Identify the intended learning objective.
2. Check whether the question actually measures that objective.
3. Rewrite the stem if it is unclear, unnecessarily difficult, or contains clues.
4. Rewrite all distractors so they are plausible and based on realistic misconceptions or common errors.
5. Remove joke answers, obvious throwaway answers, grammatical clues, answer-length clues, and wording clues.
6. Avoid “all of the above” and “none of the above.”
7. Check that no other question reveals the answer.
8. Make sure there is exactly one clearly best answer.
9. Prefer questions that require understanding, application, or reasoning rather than simple recognition when the content allows it.
10. Keep the language clear enough that the item measures subject knowledge rather than reading ability.
11. After revising, briefly state what was wrong with the original question and what was improved.
12. Do not make the question harder by making the wording more complicated. Make it better by making the assessment more valid and diagnostic.
